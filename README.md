# TechStore

Frontend completo de um e-commerce desenvolvido em **React + TypeScript + Vite**.

## Funcionalidades

- Home responsiva
- Catálogo com busca, filtros e ordenação
- Detalhes do produto
- Carrinho persistido em `localStorage`
- Cadastro e login mockados
- Perfis CUSTOMER e ADMIN
- Checkout simulado
- Histórico de pedidos
- Perfil do usuário
- Painel administrativo
- CRUD de produtos com persistência local
- React Router
- TanStack Query

## Como executar

```bash
npm install
npm run dev
